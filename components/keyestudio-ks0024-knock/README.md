# Keyestudio KS0024 knock-sensor

## Identifikation

| Felt | Værdi |
| --- | --- |
| Produkt-id | KS0024 |
| Type | Fjederbaseret slag-/knocksensor |
| Interface | `OUT`, `VCC`, `GND` |
| Output | Kort digital impuls ved slag |
| Forsyning | 5 V |

På referencefotoet er dette modulet med den synlige fjeder i en klar
plastkapsling.

## Tilslutning

`OUT` forbindes til en digital indgang, gerne en interrupt-egnet pin ved korte
impulser. Mekaniske efter-svingninger kan kræve debounce. Ingen sketches endnu.
