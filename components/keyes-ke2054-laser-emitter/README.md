# Keyes KE2054 laser-emittermodul

![Keyes KE2054 laser-emittermodul](image.webp)

## Identifikation

| Felt | Værdi |
| --- | --- |
| Produkt-id | KE2054 |
| Type | Rød laserdiode-emitter |
| Interface | `OUT`, `VCC`, `GND` |
| Forsyning | 3,3–5 V |
| Output | Digital on/off |

Boardets konstruktion og silketryk svarer til Keyes Brick KE2054. Komponenten
er en emitter, selv om den ofte sælges under navnet “laser sensor”.

## Sikkerhed og tilslutning

`OUT` forbindes til en digital udgang. Se aldrig direkte ind i strålen, ret den
ikke mod mennesker eller dyr, og undgå blanke reflekterende flader. Ingen sketches endnu.
