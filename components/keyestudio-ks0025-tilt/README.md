# Keyestudio KS0025 digital tiltsensor

## Identifikation

| Felt | Værdi |
| --- | --- |
| Produkt-id | KS0025 |
| Type | Mekanisk tilt-/kuglekontakt |
| Interface | `OUT`, `VCC`, `GND` |
| Output | Digitalt |
| Forsyning | 3,3–5 V |

På referencefotoet er dette modulet med den klare glaskapsel og bevægelige
kontakt. Det registrerer retning, ikke en præcis hældningsvinkel.

## Tilslutning

`OUT` forbindes til en digital indgang. Software-debounce anbefales, fordi den
mekaniske kontakt kan skifte flere gange under bevægelse. Ingen sketches endnu.
