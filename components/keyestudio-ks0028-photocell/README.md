# Keyestudio KS0028 fotomodstandssensor

## Identifikation

| Felt | Værdi |
| --- | --- |
| Produkt-id | KS0028 |
| Type | LDR/fotomodstand i spændingsdeler |
| Interface | `OUT`, `VCC`, `GND` |
| Output | Analogt, afhængigt af lysniveau |
| Forsyning | 5 V |

## Tilslutning og hensyn

`OUT` forbindes til en analog indgang. Modulet egner sig til relativ
lysmåling og tærskler, ikke præcis lux-måling. Kalibrér minimum og maksimum i
den aktuelle opstilling. Ingen sketches endnu.
