# Keyestudio KS0037 vibrationssensor

## Identifikation

| Felt | Værdi |
| --- | --- |
| Produkt-id | KS0037 |
| Type | Mekanisk, omnidirektionel vibrationskontakt |
| Interface | `OUT`, `VCC`, `GND` |
| Output | Digital impuls ved vibration |
| Forsyning | 3,3–5 V |

På referencefotoet er sensorelementet den sorte vandrette cylinder. Modulet
registrerer vibration, men måler ikke en kalibreret acceleration.

## Tilslutning

`OUT` forbindes til en digital eller interrupt-egnet indgang. Impulserne er
korte og kan indeholde kontaktstøj. Ingen sketches endnu.
