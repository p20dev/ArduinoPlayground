# Keyestudio KS0035 mikrofonmodul

## Identifikation

| Felt | Værdi |
| --- | --- |
| Produkt-id | KS0035 |
| Type | Analog lydsensor med elektretmikrofon |
| Interface | `OUT`, `VCC`, `GND` |
| Forsyning | 3,3–5 V DC |
| Output | Analog spænding proportional med mikrofonsignalet |

Det blå potentiometer justerer forstærkningen. Modulet måler variationer i lyd,
men er ikke en kalibreret lydtryksmåler.

## Tilslutning

`OUT` forbindes til en analog indgang, `VCC` til 3,3 eller 5 V og `GND` til
fælles stel. Modulet har ingen sketches i repoet endnu.
