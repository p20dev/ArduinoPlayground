# Keyestudio KS0015 pulssensor

## Identifikation

| Felt | Værdi |
| --- | --- |
| Produkt-id | KS0015 |
| Type | Optisk pulssensor med IR-LED og fototransistor |
| Interface | `IN`, `VCC`, `GND` |
| Output | Analogt målesignal |

En finger placeres mellem lysgiveren og fototransistoren. Den røde indikator
følger variationerne i det registrerede pulssignal.

## Tilslutning og begrænsning

Signalet forbindes til en analog indgang og kræver filtrering og tærskelvalg.
Modulet er til eksperimenter og er ikke medicinsk udstyr. Ingen sketches endnu.
